Problem Statement



Meera is analyzing a dataset of integers and wants to quickly determine if any value appears more than once. She needs an efficient approach to identify duplicate elements, and she chooses to sort the array using QuickSort to simplify the check. Can you help Meera confirm if there are any duplicate values in her data?

Input format :
The first line of input consists of an integer n, representing the size of the array.

The second line consists of n space-separated integers, representing the elements of the array.

Output format :
The output prints "The element {element} occurs at the indices {index1} and {index2}" if any value appears more than once,

If any element is repeated more than two times, then print the first repeating element and its first two repeating indexes.

Otherwise, print "All the values are Distinct".



Note: Index values are taken after sorting, and the array follows 0-based indexing.



Refer to the sample output for formatting specifications.

Code constraints :
The given test cases fall under the following constraints:

1 ≤ n ≤ 100

−109 ≤ nums[i] ≤ 109

Sample test cases :
Input 1 :
4
1 2 3 1
Output 1 :
The element 1 occurs at the indices 0 and 1
Input 2 :
7
7 4 6 4 4 6 1
Output 2 :
The element 4 occurs at the indices 1 and 2
Input 3 :
5
9 8 7 4 6
Output 3 :
All the values are Distinct
