Problem Statement



Alice, a computer science student, is learning about sorting algorithms. She is particularly interested in the QuickSort algorithm. Using the QuickSort algorithm, she needs to sort an array of integers.



Help Alice by providing a program that accomplishes the task.

Input format :
The first line of input contains the integer N, representing the number of elements.

The second line contains N space-separated integers representing the array elements.

Output format :
The output prints the sorted array separated by space.



Refer to the sample output for formatting specifications.

Code constraints :
The given test cases fall under the following specifications:

1 ≤ N ≤ 20

1 ≤ elements ≤ 100

Sample test cases :
Input 1 :
5
80 40 20 50 30
Output 1 :
20 30 40 50 80 
Input 2 :
5
19 3 67 54 23
Output 2 :
3 19 23 54 67
