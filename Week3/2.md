Problem Statement

You are working on a project to help urban planners optimize the installation of a fiber optic network between various buildings. Given the number of buildings and the costs associated with laying fiber optic cables between each pair.

Your task is to develop a program that implements Prim's algorithm to determine the minimum cost to connect all buildings.

Input format :
The first line contains an integer N, representing the number of buildings.

The next N × N matrix follows, where each element represents the cost of laying a fiber optic cable between two buildings. A value of 0 indicates no direct connection.

Output format :
The output prints the "Spanning Tree Matrix:" where each element shows the connections between buildings in the minimum spanning tree.

Then, print "Total Cost: " followed by the minimum total cost required to connect all the buildings.

Refer to the sample output for formatting specifications.

Code constraints :
1 ≤ N ≤ 10
